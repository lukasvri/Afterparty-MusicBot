# Muse-spelaren som referanse

Desse filene er kopierte frå den eksisterande lokale Muse-installasjonen sine tilpassingar (`overrides`), 14. oktober 2026. Dei er referansekode, ikkje ein ekstra motor som blir starta. Den aktive tilpassinga ligg i `../../src/player-message.ts` og `../../src/discord.ts`.

Pause/Fortsett ⏸️/▶️, neste ⏭️, stopp ⏹️, gjenta 🔁, bland kø 🔀 og favoritt ⭐ følgjer Muse-spelaren. Dei to opphavlege knapperadene og tidslinja er tilbake. Biletet ligg på sida etter det nyaste ønsket frå brukaren. `build-embed.ts` og `get-progress-bar.ts` er henta frå den bevarte Muse-containeren (muse-local:2.11.8-sync-fix).
