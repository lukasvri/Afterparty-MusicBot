# Bidrag

Opne ei sak med konkret problem, steg for å gjenskape feilen og venta resultat. Fjern nøklar, brukar-ID-ar og private loggdata.

Bruk ein eigen grein. Køyr relevante testar og `npm run project -- check` før ein pull request. Endringar i lyd skal òg bestå FFmpeg-testane. Bevar serverisolasjon, autorisasjon, køversjonar og skiljet mellom vanleg Discord-musikk og offentlege konsertar.

Bruk testdata og eigne testkontoar. Produksjonsdatabasar, `.env`, backup og lokale hosting-ID-ar skal ikkje inn i Git. Nye bidrag blir leverte under prosjektet sin MIT-lisens.
